## 操作

默认载入官网只读快照中的 32 名舰队成员，每人从 210 个有武装抽签条目（含改型与涂装版本）真实《星际公民》舰船中等概率随机获得一艘，允许同型舰。舰船标签保持成员原名；战场右侧透明榜显示真实头像、名字、分配舰型和带骷髅标志的本局击杀，击杀降序排列，同分按参战顺序，换位有平滑动画。点击成员定位其飞船并查看状态。

「参战成员」可选择部分成员（含 10 / 30 人快捷项）；「重新抽签」更换舰船分配；「重置」保留本局分配、出生种子并清零战斗。刷新重新载入名单并抽签。运行或暂停期间不能更换成员和分船。支持暂停/继续、1×/2×/4×、滚轮缩放、拖动、全屏和可收起的手机排行榜。导入的图片与校准存在本模块独立 IndexedDB，不读取或写入第一款游戏战绩。

每船独立寻敌、拦截、平滑转向、惯性飞行、距离控制、分离避障和自动开火，舰体归零后淘汰成员，按所选模式结算。支持固定激光、多个独立炮塔与射界、追踪导弹、护盾、爆炸和残骸。胜负由真实弹道伤害决定，没有计时强制扣血。

## 源码边界

| 目录/文件 | 用途 |
| --- | --- |
| `src/sim/` | 纯 TypeScript 固定 60 Hz 战斗与几何；不依赖 React、Pixi、DOM 或真实时间 |

| `src/data/ships.json` | 224 型舰船（210 个成员条目、5 型 BOSS、3 个退出/姿态暂缓条目、6 个无武装条目）、尺寸、AI、武器与平衡参数 |

| `src/assets/library.ts` | 清单校验、PNG/WebP 导入、IndexedDB 保存、独立素材包 |
| `src/ui/` | 成员击杀榜、参战选择、状态检查、图片与挂点校准工具 |

## BOSS 与完整目录

顶部按钮选择四种模式，默认每次重新抽签随机切换：

- **赏金猎人**：成员同队、无友伤；随机一艘 BOSS，开战后从随机外围方向入场，随后 20 艘剜度僚机从独立随机外围分批飞入。击毁 BOSS 即获胜并撒花。
- **成员大乱斗**：只有成员，各自战斗，最后一名幸存者获胜。
- **红蓝团队战**：成员分为红蓝两队，从战场两侧出生，同队无友伤，敌方全灭获胜。
- **挑战模式**：无僚机，依次挑战拳手 → 奥丁 → 飞马座 → 孟加拉 → 复仇。每波按存活编队火力生成固定耐久预算；间隔 4.5 秒（内部模拟 6 秒），存活成员恢复少量舰体和护盾，已淘汰者不复活。五波全胜撒花。

准备界面只有成员，不预先部署敌方。BOSS 池的 5 型已移出成员抽签池，使用橙红标识与独立血条。全部 BOSS 使用原舰型图库尺寸，不额外放大；取消整船圆圈，保留局部受击闪光。

## 镜头与节奏

焦点默认开启，准备时保留全景，实际交火后进入自动观战。按开火、命中、受击和出镜记录选取成员与对手，正常镜头约 5 秒；巨型 BOSS 展示局部交火区域。滚轮、按钮和双指缩放保留手动锁船/自动焦点并持续跟随；手动锁船时拖动也不解锁。只有点空白、焦点/全景或正常重置清除手动锁定；自动焦点下原拖动转自由视角行为保留。点船或成员榜会适配近景并持续跟随；缩放范围始终全局统一。船名和血条贴近实际轮廓下方。小按钮重新开启焦点，「全景」查看整个战场。镜头不更改战斗结果。

224型使用共同的真实资料转换/缺项估计，武器按公开配装或明确模拟回退配置：小船转向更快，大船厚重、重炮慢射。伤害预算抑制同一帧密集齐射秒杀；挑战 BOSS 有更强的抗爆发、递增耐久和火力。所有数值为本游戏平衡参数，详见 `docs/BALANCE.md`。

武器更新使用 `scripts/import-fleet-weapons.py` 与 `node scripts/apply-fleet-weapons.mjs`，详见 `docs/SIGNATURE-WEAPONS.md`，不要为只改武器而重写血盾/飞行。完整数据生成的源为ship-reference-facts，转换规则为ship-game-balance，BOSS模式规则为boss-mode-balance；`defense-balance.json`仅负责原抗爆发/恢复/非BOSS输出。相关修改运行 `npm run balance:generate` 同步全224舰与默认图库尺寸、武器表。随后运行测试并重新构建。本版基准耗时系数为上版 0.75，以固定 60 Hz 步数执行 4/3 倍基准推进；界面计时与现实 1×秒数对应，2×/4×再增加步数。新机动与随机阵容仍会影响实际局长。

完整 STARJUMP 目录为 315 个分组、391 个变体元数据；默认俯视图 315 张已保存到下载目录。完整原始 JSON 在 docs/starjump-full-catalog.json。完整目录还包含地面载具、角色、模块、站点与特效，不全部进入飞船抽签。筛选原因可见 docs/catalog-classification.json。

左下角战报显示被击毁成员和击杀者，带深色底板、加粗与文字阴影，保留最近三条直到被新记录替换，重置清空。
