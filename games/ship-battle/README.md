# 星际飞船大乱斗

独立的《星际公民》2D 俯视自动战斗游戏，TypeScript + React + PixiJS 8 + Vite。没有账户、服务器、经济、手动驾驶或联网玩法。

本模块在独立 Worktree `gvy-ship-battle`、分支 `feat/ship-battle-20261021` 开发。本分支仅增加本目录，未编辑官网首页、第一款游戏、公共弹窗、现有路由或官网构建脚本；未推送、合并或部署线上。

## 运行

在此目录执行（Node.js 22.12+，本机已验证 Node 24.19）：

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:5187/games/ship-battle/ 。生产版本：

```sh
npm run build
npm run preview
```

构建输出为本目录下的 `dist/`。其内容应完整复制到网站输出的 `games/ship-battle/` 目录；不能将 `dist/` 目录本身嵌套进去。无需安装官网依赖，也无需改变官网现有脚本。

```sh
npm test
npm run build
```

浏览器验证使用 Playwright CLI，见 `docs/TESTING.md`。`npm run check` 合并运行引擎/素材测试与 TypeScript / Vite 构建。

## 操作

默认载入官网只读快照中的 32 名舰队成员，每人从 217 个抽签条目（含改型与涂装版本）真实《星际公民》舰船中等概率随机获得一艘，允许同型舰。舰船标签保持成员原名；战场右侧透明榜显示真实头像、名字、分配舰型和带骷髅标志的本局击杀，击杀降序排列，同分按参战顺序，换位有平滑动画。点击成员定位其飞船并查看状态。

「参战成员」可选择部分成员（含 10 / 30 人快捷项）；「重新抽签」更换舰船分配；「重置」保留本局分配、出生种子并清零战斗。刷新重新载入名单并抽签。运行或暂停期间不能更换成员和分船。支持暂停/继续、1×/2×/4×、滚轮缩放、拖动、全屏和可收起的手机排行榜。导入的图片与校准存在本模块独立 IndexedDB，不读取或写入第一款游戏战绩。

每船独立寻敌、拦截、平滑转向、惯性飞行、距离控制、分离避障和自动开火，舰体归零后淘汰成员，按所选模式结算。支持固定激光、多个独立炮塔与射界、追踪导弹、护盾、爆炸和残骸。胜负由真实弹道伤害决定，没有计时强制扣血。

## 源码边界

| 目录/文件 | 用途 |
| --- | --- |
| `src/sim/` | 纯 TypeScript 固定 60 Hz 战斗与几何；不依赖 React、Pixi、DOM 或真实时间 |
| `src/render/BattleRenderer.ts` | Pixi WebGL 渲染、相机、特效、鼠标输入、固定步长累积 |
| `src/data/ships.json` | 224 型舰船（217 个成员条目、5 型 BOSS、2 个暂缓条目）、尺寸、AI、武器与平衡参数 |
| `src/data/members.json` | 官网 32 人只读成员快照，与独立头像副本 |
| `src/assets/library.ts` | 清单校验、PNG/WebP 导入、IndexedDB 保存、独立素材包 |
| `src/ui/` | 成员击杀榜、参战选择、状态检查、图片与挂点校准工具 |
| `src/bridge.ts` | 带来源检查的同源 iframe 通信 |
| `public/assets/ships/` | REA 捕获并逐文件校验的真实 PNG 与清单 |

增加舰型时在 JSON 中加入唯一 ID、尺寸、AI 参数、挂点，并在素材清单添加对应图片记录；无需改动引擎。当前上限为 100 名成员，另加最多 21 艘敌方舰船，首版验收目标为桌面 30 艘。100 艘已有计算测试，浏览器以当前真实 32 人名单为目标；后续 100 人浏览器性能仍需优化。

## 真实舰船与校准

当前战斗图库 224 个舰型（217 个成员条目 + 5 型 BOSS + 2 个暂缓条目），含原定首批：F8C Lightning、Gladius、Arrow、F7C Hornet Mk II、Sabre、Scorpius、Vanguard Warden、Constellation Andromeda、Perseus、Polaris、Idris-P、Javelin。

真实 PNG 来自 STARJUMP 公共 CDN；由 REA 网络捕获保留原始字节，详见 `docs/STARJUMP.md` 与 `docs/starjump-sources.json`。原图舰首均朝左，渲染配置为 `noseDegrees: -90`。展示长度来自 2026-10-17 公共快照，宽度依原图长宽比计算，保留外形比例。该投影宽度不是独立核验的官方船宽。

首批 12 型喷口和武器挂点按图目测；其余舰型使用按尺寸分级的暂定模板，**不是精确的官方三维挂点数据**，全部仍待逐船校准，标记 `calibrated: false`。素材管理器可逐项调整喷口、挂点、独立炮塔的朝向/射界/射程/冷却/伤害，确认后另存本机。盾、血量、伤害、速度、转速是本模拟器的平衡参数，不表示实机数据。

素材按用户明确要求用于非商业舰队项目，并保留 CIG / STARJUMP 来源；尚未独立取得 STARJUMP 对渲染图再发布的明确许可，不能将本仓库视为素材的开放许可证。技术取得证据不证明版权归属或许可。没有使用两款参考游戏的美术或直接复制其代码。

官网 Codex 直接阅读 `docs/INTEGRATION.md` 接入；独立的同源弹窗示例在 `/games/ship-battle/embed-example.html`。

## BOSS 与完整目录

顶部按钮选择四种模式，默认每次重新抽签随机切换：

- **赏金猎人**：成员同队、无友伤；随机一艘 BOSS，开战后从随机外围方向入场，随后 20 艘剜度僚机从独立随机外围分批飞入。击毁 BOSS 即获胜并撒花。
- **成员大乱斗**：只有成员，各自战斗，最后一名幸存者获胜。
- **红蓝团队战**：成员分为红蓝两队，从战场两侧出生，同队无友伤，敌方全灭获胜。
- **挑战模式**：无僚机，依次挑战拳手 → 奥丁 → 飞马座 → 孟加拉 → 复仇。每波按存活编队火力生成固定耐久预算；间隔 4.5 秒（内部模拟 6 秒），存活成员恢复少量舰体和护盾，已淘汰者不复活。五波全胜撒花。

准备界面只有成员，不预先部署敌方。BOSS 池的 5 型已移出成员抽签池，使用橙红标识与独立血条。全部 BOSS 使用原舰型图库尺寸，不额外放大；取消整船圆圈，保留局部受击闪光。

## 镜头与节奏

焦点默认开启，准备时保留全景，实际交火后进入自动观战。按开火、命中、受击和出镜记录选取成员与对手，正常镜头约 5 秒；巨型 BOSS 展示局部交火区域。滚轮、拖动立即关闭焦点，保持手动视角；点船或成员榜会适配当前船的近景并持续跟随；滚轮最远与最近范围始终全局统一。船名和血条贴近实际轮廓下方。小按钮重新开启焦点，「全景」查看整个战场。镜头不更改战斗结果。

224 型统一采用舰级与定位的防御、输出和机动配置：小船转向更快，大船厚重、重炮慢射。伤害预算抑制同一帧密集齐射秒杀；挑战 BOSS 有更强的抗爆发、递增耐久和火力。所有数值为本游戏平衡参数，详见 `docs/BALANCE.md`。

平衡源表为 `src/data/defense-balance.json`；修改后运行 `npm run balance:generate` 同步 224 型配置及图片挂点中的战斗数值。随后运行测试并重新构建。本版基准耗时系数为上版 0.75，以固定 60 Hz 步数执行 4/3 倍基准推进；界面计时与现实 1×秒数对应，2×/4×再增加步数。新机动与随机阵容仍会影响实际局长。

完整 STARJUMP 目录为 315 个分组、391 个变体元数据；默认俯视图 315 张已保存到下载目录。完整原始 JSON 在 docs/starjump-full-catalog.json。完整目录还包含地面载具、角色、模块、站点与特效，不全部进入飞船抽签。筛选原因可见 docs/catalog-classification.json。

左下角战报显示被击毁成员和击杀者，带深色底板、加粗与文字阴影，保留最近三条直到被新记录替换，重置清空。

## 最新界面、机动与图库核查

界面改为一条紧凑信息栏和底部工具栏。开始、暂停、重置、重新抽签及参战成员集中展示，窄窗口分行；292px iframe 仍保留按钮。排行榜按钮位于右上角、全屏左边。排行榜悬浮在战场右侧，无面板/行背景。素材管理已从正常界面移除，开发校准可使用 `?assets=1`。

小船交替进退和横移，来袭弹道或近期受击触发短促防御动作；重型战机较缓，大舰低速斜向推进。避让和重叠修正按尺寸权重处理。没有闪避无敌帧。武器主炮、近防与反大型舰鱼雷分别承担不同任务，舰型、大小与阵容共同影响胜负；完整系数见平衡源表与 BALANCE.md。

自动焦点按舰型适配，保留较远视野；点击单船近看。镜头跟随每帧位移，只平滑构图变化，避免高速船跑出画面。其他交火可用时约 5 秒切换。滚轮范围保持全局统一。

独立窗口预览：`/games/ship-battle/popup-preview.html`，模拟官网居中、右下停靠和恢复，保留 iframe 视口，用 `.arena-stage` 标记裁切战场。没有改动官网公共组件。

胜利撒花参照第一款游戏的金/白/青色金属纸片、横向摇摆和旋转；桌面 72 片，窄屏 40 片，约 7 秒自然结束，独立于战斗倍速。成员混战和合作胜利均庆祝，失败不撒花。

全部 224 张 PNG 已核查可读取且有透明背景。Endeavor Master Set 拆件展示图与 Syulen 立式展示姿态暂缓抽签；普通 Endeavor 完整船体保留。当前可抽签 217 条，加 5 型 BOSS，归档仍为 224 张，见 `docs/ASSET-AUDIT.md`。

陨石采用 REA 完整目录中的单块透明 PNG，有大有小，阻挡弹道并造成撞击伤害。小船高速撞击可以直接爆炸；环境击毁单独统计。可复现批量模拟：`CASES=32 REPORT=/tmp/balance.json npm run balance:sample`。
