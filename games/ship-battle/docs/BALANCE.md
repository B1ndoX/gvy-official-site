# 战斗设计与调参

本文描述游戏模拟参数，不是《星际公民》官方血量、护盾或实机武器数据。尺寸依据图库展示长度，外形比例保留；喷口与武器坐标仍是待逐船校准的模拟模板。

## 四种模式

| 模式 | 编队与目标 | 结算 |
| --- | --- | --- |
| 成员大乱斗 brawl | 每位成员独立阵营，不刷 NPC | 最后一艘存活成员舰获胜 |
| 赏金 bounty | 成员合作，随机一艘 BOSS 与 20 艘剜度僚机 | BOSS 被击毁即胜利；成员全灭失败 |
| 挑战 challenge | 成员合作，拳手→奥丁→飞马座→孟加拉→复仇；无僚机 | 五轮全胜通关，成员全灭失败 |
| 团队 teams | 成员交替分为红蓝，从左右两侧出生，同队无友伤 | 敌队全灭获胜 |

准备阶段只有成员；开战后 BOSS 从随机外围方向飞入，僚机延迟分批从各自随机外围位置飞入。全部舰型包括 BOSS 均使用正常图库比例，不再放大。

## 连续尺寸与定位

`src/data/defense-balance.json` 是平衡源表；`npm run balance:generate` 生成 `ships.json` 与内置素材清单中的战斗数值。9/20/30/55/120/250/480/1000/2400 米作为参考长度，用对数插值连续计算舰体、盾和整船输出，避免 34 米与 35 米突然跨档。轻/中/重战斗机、隐形、竞速、军事、运输、民用、多用途有各自系数。class 的三档仅用于行为分类，数值不直接跳档。

速度、加速和转向均随长度平滑下降。主武器冷却约从 0.32 秒增长到 3.6 秒，导弹约 9–15 秒；大船的单发更重、射速更低。理论整船 DPS 按武器用途分配，每座炮塔有独立目标、射界、角度、转速、冷却和实体弹道。主炮优先较大目标，近防炮优先小目标，目标黏性避免炮塔在多个目标之间反复摆动而开不了火。

## 机动与反制

小型舰以接近、突击、惯性冲出、回转再次进攻的周期作战，正面交火后不会永久刹停对射。中型舰回转与横移较缓；大型舰与 BOSS 持续低速推进，久未命中会换航线。全体有分离避让与陨石前视避障。位移修正按尺寸质量分配，小船不会把巨舰推走。

小船会预测来袭弹道的最近交点，短时横移加速规避；受击也能触发防御机动。间隔、持续时间、加速和侧移随类型变化，没有无敌帧。重炮弹速更低，转速和对高速横移目标的跟踪误差较大；近防炮弹速和转速较高，但每发较轻。

轰炸机携带低转弯能力的反大型舰鱼雷，围绕大型目标保持发射距离；鱼雷对较大船的效能按 `(目标长度/40)^1.65` 平滑增长，上限 24，对很小船最低 0.12。它仍必须真实飞行、命中，可被陨石挡住，并受到目标抗爆发预算限制。拦截机优先追击轰炸机，近防舰可保护重舰。它们形成阵容反制，而不是固定抽签胜负；轻型舰不保证能单挑任何巨舰。

固定对照（8 个种子、相同起始距离、无陨石）中，Eclipse 对无护航 Javelin 胜 7 局，对 Hammerhead 胜 0 局；Gladius 对 Eclipse 胜 8 局，Javelin 对 Hammerhead 胜 8 局。该对照验证方向，不代表完整舰队的通用胜率。

## 防御、BOSS 与时间

护盾在停止受击 7 秒后以最大盾值每模拟秒 0.2%恢复。每船有按最大舰体+盾计算的连续伤害预算，密集齐射超过预算的伤害被缓冲：成员/僚机瞬间容量 20%、每模拟秒恢复 14%；赏金 BOSS 为 8%/6%，挑战 BOSS 为 5%/3.5%。这保证正常武器集火下小船有反应时间、BOSS 不会三秒消失。陨石高速撞击按用户要求可以直接击毁小船，不受此保护。

BOSS 基础舰体除复仇以外采用 2 倍，复仇不加这层倍数；合作模式另有平衡与人数系数。挑战在每轮出生时，结合当时实际存活火力与按开局人数/损失估算的参考火力生成固定耐久预算；不完全按当前输出抵消阵容差异。45/55/65/75/90 模拟秒是预算参考，不是强制结束计时。BOSS 出生后成员掉血或阵亡不会令其回血或改属性。近防与主炮均独立工作；BOSS 额外炮塔为模拟配置，不宣称官方挂点。

轮间 6 模拟秒整备，存活成员回复最大舰体 15%、盾 35%，阵亡不复活。当前 bossDamageMultiplier=4、赏金防御倍率5.6、挑战输出再乘0.45、挑战预算再乘1.1；这些系数反映实际命中率与连续五关损耗。完整系数及样本结果以 `defense-balance.json`、`TESTING.md` 为准。不要仅调伤害：火力预算、目标选择、命中率与续航共同决定难度。

渲染器固定 60 Hz 累积步进。基准耗时系数 0.75：引擎原始秒数乘 0.75 为界面 1×秒数；2×/4×只增加固定步数。镜头导播与撒花按现实时间计算，不跟随战斗倍速。引擎不使用墙钟、随机判胜或到时强制扣血。

## 陨石

12 块静态陨石分小/中/大尺寸，出生时避开舰船。使用 STARJUMP 单独透明 PNG，变化旋转与大小；没有拿整张陨石带图片当一个实体。圆形碰撞代理略保守，弹丸使用扫掠线段与圆相交，飞船按当前速度撞击扣盾/舰体。小于 35 米的船高速撞击可直接爆炸，击毁记录标明「陨石撞击」，不把环境死亡加到任何成员击杀数。

## 观战

焦点默认开启，开战前全景，真实开火/命中/受击后选取成员交火；不按两连杀门槛选镜头。其他交火可用时约 5 现实秒切换，单一交火会继续保留。自动镜头按船长适配约 32–48 个基础 UI 像素的舰长，点击单船近看约 100 像素；巨型对手可局部入镜。跟随每帧主体位移，仅平滑构图偏移，避免高速船跑出镜头。

滚轮/拖动立即关闭焦点并保持手动视角；缩放上下限采用全局世界尺度，与选中舰型无关。点击成员/船转为手动跟随，焦点按钮重启自动导播。名字和条位于真实透明轮廓下方。暂停冻结模拟与导播，重置恢复焦点待命。

## 复现与迁移

```sh
npm run balance:generate
CASES=32 OFFSET=0 MODES=bounty,challenge REPORT=/tmp/ship-balance.json npm run balance:sample
npm test
npm run build
```

试验用 `DAMAGE` / `DEFENSE` / `BUDGET` 环境变量只改采样进程，不写生产配置。验证须使用另一段未参与调参的种子；通关率只作为样本估计，尤其受成员人数和抽到的舰型影响，不能每局强制达标。

combatVersion 4 升级会保留用户 PNG、舰首、尺寸、已有喷口/挂点坐标，更新旧版挂点的伤害、冷却、射程、弹速、用途与转速，并补齐新 BOSS 独立炮塔。当前版本用户再保存的自定义值保留；自定义属性不受默认平衡结论覆盖。
