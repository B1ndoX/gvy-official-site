## 单一数据链

1. 机器人留存的4.10.2-LIVE.12913470同版本ship-loadouts/component-matrix为主；官方矩阵/补充资料按字段补缺，各输入SHA保留。只读，不访问NAS或修改机器人，不引入价格/货物/燃油等无关内容。
2. `ship-reference-facts.json`存原始尺寸、总HP、质量、SCM、偏航、护盾配置/容量、装甲倍率及每字段来源/缺项。`fleet-weapon-loadouts.json`与`weapon-catalog.json`存配装事实。
3. `ship-game-balance.json`＋`scripts/ship-stat-model.mjs`以同一连续函数转换所有舰船，包括5型BOSS，没有按舰名调血量/速度。`weapon-size-balance.json`＋共享型号表决定单炮参数。
4. `npm run balance:generate`统一生成ships、manifest、ship-game-values及weapon-game-values。BOSS难度只由独立`boss-mode-balance.json`在遭遇创建时应用，不回写基础舰型。

当前字段覆盖：原始长度220、宽/高219、质量209、SCM200、偏航164、总HP196、可解析护盾容量190（其中部分按尺寸/类别或型号变体估计），总模型224。加速度全部明确估算。武器189完整型号快照、25尺寸数量参考/部分型号估计、6无武装、4未核实模拟；3型缺完整武器清单的BOSS仍不得宣称真实完整。

## 源数据质量与投影

原始HP是totalHp总值，未核验独立核心毁伤HP；不把装甲血量、护盾发生器自身血量与盾容量简单相加。护盾型号多容量时保留范围，采用中位值并标明估计；资本级C/未知S10不能误解析为S1。

原图长宽比保持。世界展示长度使用可用来源，投影宽按原PNG比例，真实物理宽/高另存；不把原始beam硬套图片造成拉伸或炮口悬空。10条尺寸与模型相差超过1.6倍的记录（含毛毛虫长高疑似颠倒、不同姿态/旧尺寸）保留原值并标记geometryConflict，暂沿用原模型长度，明确估计而非已核实官方尺寸。另4条缺长度也保留模型估计。该规则统一，不是按胜率给某船改大小。

## 全舰共同换算

基准Gladius来源：21米、48552.06kg、6110总HP、6336盾容量、226 SCM、偏航52°/秒。

| 项目 | 统一公式或规则 |
| --- | --- |
| 舰体 | 13600 × (来源总HP / 6110)^.38 × 全局舰体系数（当前.75）；范围1800–1100000 |
| 护盾 | 8800 × (来源盾容量 / 6336)^.42 × 全局护盾系数（当前.75）；范围500–500000 |
| 速度 | 250 × (SCM / 226)；范围32–380游戏单位/模拟秒 |
| 转向 | 来源偏航°/秒 × π/180 × 2.8；范围.08–4.5 rad/模拟秒 |
| 加速度估计 | 游戏速度 / [1.9 × (质量 / 48552.06)^.17]；范围4–300 |
| 缺总HP估计 | 6110 × (长度 / 21)^2.1，再走同一血量转换 |
| 缺盾容量估计 | 6336 × (长度 / 21)^1.4，再走同一护盾转换 |
| 缺质量估计 | 48552.06 × (长度 / 21)^2.2 |
| 缺SCM估计 | 226 × (长度 / 21)^-.16 |

未对已知真实HP再叠角色血量系数。原战斗角色仅保留行为用途（轻战机闪避等），不参与上述耐久换算。原始护盾快速回充没有直接搬入，继续统一7模拟秒未受击后每模拟秒恢复最大盾.2%，防小游戏持续拉扯不结算。

装甲只用来源物理/能量承伤倍率，限制.25–1，缺项为1且明确未知。护盾先吸收，溢出武器伤害再乘对应装甲倍率；实弹/龙骨炮/导弹/鱼雷按物理，普通激光/持续光束按能量。畸变在其基础上保留15%舰体溢出。不模拟逐部件装甲HP消耗/穿深/资源网络，不冒称原作完整毁伤。环境/船体碰撞不套此武器装甲倍率。

## 武器与碰撞

同型号同尺寸同类别共享单炮值，再按真实炮管逐枚发射；不合并伤害、不按炮管数量递减、不按每舰旧DPS抹平。尺寸曲线、型号参数和已确认主武器见SIGNATURE-WEAPONS。缺可靠清单的4舰保留明确模拟发射位置，但也使用统一尺寸/类别曲线；模拟弹仓12枚不冒称真实容量。英仙座独立双联S8、北极星28枚有限S10、连续主光束5Hz、原近防最多2组只拦截规则保持。

原非BOSS输出1.265、成员持续光束.9、非BOSS持续光束再.9保持。护盾/船体普通抗爆发：成员瞬间20%/每模拟秒14%，赏金BOSS8%/6%，挑战BOSS5%/3.5%；指定S8/S10/龙骨炮对普通目标放行，BOSS保护保留。浮点余量小于1e-8归零，避免新整数血量在应击毁时残留不可见极小值。

船体碰撞按真实质量或统一质量估计分配，80法向接近速度以下免伤、普通单次最多5%船体、实际1秒合计8%、高速小船正撞大船致命的严格条件不变，所有阵营同一设置。20陨石目标（6/7/7环带、原范围、避免出生与彼此；极拥挤条件可能少于20）；快小船撞陨石可致命、环境死亡不计成员击杀。

## BOSS模式层

所有BOSS先生成相同标准的基础HP/盾/机动/武器；取消旧按BOSS名字单列基础血量以及“除复仇外再×2”的隐藏基础处理。赏金/挑战在创建遭遇时才读取独立boss-mode-balance：

- 开局人数以32人为基准，耐久随人数线性、输出随人数平方根连续增长，没有63→64突然跨档。出生后不会因成员阵亡回血或动态改属性。
- 赏金基础耐久×9，BOSS武器模式系数3；20僚机沿用原配置。仅真实BOSS击毁即胜。
- 挑战输出×3×.4（先前.45/.525为过程对照）。五关依次拳手→奥丁→飞马座→孟加拉→复仇；无僚机。
- 挑战耐久预算：实际开局编队火力权重.35、每名成员650参考火力权重.65，乘45/55/65/75/90模拟秒与1.0预算系数，并不低于基础舰体×人数×1.5＋人数缩放盾。它是遭遇出生时固定预算，不是计时扣血或强制判胜。
- 轮间6模拟秒，存活舰体恢复15%、盾35%，阵亡不复活。BOSS缺原始数据仍按统一缺项曲线估算并标明，不伪造为原作完整数值。

诊断8挑战5胜；进程内输出对照3.5为3/8、3.8为1/12，但这些是尺寸冲突保护最终完成前的过程样本，不当最终概率。最终独立冻结样本为32乱斗均值115.59实际秒、32挑战10通关31.25%、16赏金13通关81.25%，80局全结束；详细条件和区间见TESTING最新区；不能复用版本13的12.5%或更早25%/2分钟统计。
